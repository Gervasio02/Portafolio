Principios de ingeniería

  1. Las reglas viven en el servidor

    La interfaz puede ocultar un botón, pero es la API la que decide si tienes permiso.

  2. La base de datos tiene la última palabra

    Restricciones únicas y transacciones en PostgreSQL, en vez de esperar que dos peticiones nunca choquen.

  3. Probar contra una base real

    Las pruebas de API usan PostgreSQL de verdad, no un simulacro.

  4. Cada cambio pasa por CI

    Si las pruebas pasan, la app se despliega sola en Azure; si fallan, sigue la versión anterior.
