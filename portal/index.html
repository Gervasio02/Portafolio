TaskFlow

Un tablero Kanban para equipos que preparan entregas y atienden incidentes. El panel de control muestra lo atrasado y lo que está por vencer según el SLA de cada tarjeta.

Lo difícil

Que el orden de las tarjetas no se rompa cuando dos personas las mueven al mismo tiempo. Las reordeno dentro de una transacción en PostgreSQL, y los permisos (dueño, editor, lector) se validan en la API, no en la pantalla.

ReservaYa

Reserva de canchas deportivas con tarifas según el horario, comprobante, cancelación y un panel de ocupación para el recinto.

Cómo trabajo

Cuatro costumbres que repito en todos los proyectos.

  1. Las reglas viven en el servidor

    La interfaz puede esconder un botón, pero quien decide si tienes permiso es la API.

  2. La base de datos tiene la última palabra

    Uso restricciones y transacciones en vez de confiar en que dos peticiones nunca lleguen juntas.

  3. Pruebo contra una base real

    Las pruebas de API corren sobre PostgreSQL de verdad. Así salen los errores que en producción dolerían.

  4. Nada llega a producción sin pasar por CI

    GitHub Actions prueba cada cambio y, si todo pasa, publica una nueva versión en Azure. Si algo falla, sigue la anterior.
