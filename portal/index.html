Gestión de equipos

TaskFlow

Un tablero Kanban para equipos que preparan entregas y atienden incidentes. El panel de control muestra lo atrasado y lo que está por vencer según el SLA de cada tarjeta.

Lo difícil

Que el orden de las tarjetas no se rompa cuando dos personas las mueven al mismo tiempo. Las reordeno dentro de una transacción en PostgreSQL, y los permisos (dueño, editor, lector) se validan en la API, no en la pantalla.

Inventario · .NET

BodegaNet

Consulta qué hay en cada bodega, registra entradas, salidas y traslados, y revisa qué productos necesitan reposición.

Lo difícil

Que el stock nunca quede negativo aunque lleguen dos salidas a la vez. Cada saldo usa concurrencia optimista dentro de una transacción con reintentos, y la base tiene su propia restricción. Una prueba lanza 10 salidas simultáneas sobre 10 unidades y comprueba que solo pasan las que caben.

  • C#
  • ASP.NET Core
  • EF Core
  • PostgreSQL
  • xUnit

Reservas

ReservaYa

Reserva de canchas deportivas con tarifas según el horario, comprobante, cancelación y un panel de ocupación para el recinto.

Lo difícil

Dos personas confirman el mismo turno en el mismo segundo. Una restricción en la base de datos garantiza que solo una se lo quede, y la otra recibe un mensaje claro en vez de un error. También tuve que cuidar las fechas con la zona horaria de Chile.

  • React
  • FastAPI
  • SQLAlchemy
  • PostgreSQL
  • pytest

Comercio electrónico

TiendaNova

Una tienda con catálogo, variantes, cupones, pedidos y devoluciones, más un panel para administrar el inventario. Los pagos son simulados.

Lo difícil

El doble clic en «pagar». El checkout es idempotente: aunque el pedido llegue dos veces se cobra una sola vez, y el stock se descuenta en la misma transacción para que nunca se venda más de lo que hay.

Juego de deducción

Interrogatorio

Abres un expediente, revisas las pruebas, interrogas a los sospechosos y buscas contradicciones antes de acusar a alguien.

Lo difícil

Que la solución no se filtre. El caso se genera en el servidor a partir de una semilla y la API solo entrega lo que el jugador ya descubrió. También le puse límites de peticiones para poder publicarlo sin miedo al abuso.
