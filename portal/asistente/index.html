Pregúntale a mi portafolio

Una red neuronal hecha a mano.

El chat de este sitio no usa ChatGPT ni ninguna API externa. Es un perceptrón multicapa que programé desde cero: lo entreno en Python con NumPy (escribí la retropropagación y el optimizador Adam a mano) y lo ejecuto en tu navegador con JavaScript. Tu pregunta nunca sale de tu equipo para ser respondida.

Qué pasa con tu pregunta

  1. NormalizoMinúsculas, sin tildes ni signos. Quito palabras vacías como «el» o «para».
  2. Extraigo rasgosRaíces de palabras, pares de palabras y trigramas de letras (toleran errores de tipeo).
  3. Hashing trickCada rasgo cae en una de 2048 posiciones con FNV-1a: no necesito guardar un vocabulario.
  4. Capa oculta96 neuronas con activación ReLU combinan esos rasgos.
  5. SoftmaxUna probabilidad para cada una de las 48 intenciones que conoce.
  6. Respondo o preguntoSi la probabilidad más alta no supera el umbral, admito que no sé y guardo la pregunta para aprenderla.

    Cómo sigue aprendiendo

    1. Si no sabe responder, o alguien marca «no me sirvió», la pregunta se guarda de forma anónima.
    2. La reviso en mi panel privado y la agrego como ejemplo en asistente/conocimiento.yml.
    3. Al subir el cambio, GitHub Actions vuelve a entrenar la red, corre las pruebas y publica el modelo nuevo.

    Lo más difícil fue que Python y JavaScript conviertan el texto en exactamente el mismo vector: una tilde tratada distinto bastaba para que la red respondiera otra cosa. Una prueba automática compara ambos lados en cada cambio. Ver el código.
